# Website review — October 26, 2026

## Changes

- Replaced the external form JavaScript dependency with direct submission, a 20-second timeout, duplicate-submit protection and confirmed-success handling.
- Kept native form submission as a no-JavaScript fallback. Retained the existing Formspree endpoint, email and phone.
- Made company and facility selection optional; removed the preselected facility assumption.
- Added a French quote page, French request feedback, language links and equivalent-page language metadata; added the quote page to the sitemap.
- Fixed CSS hidden-state precedence for search results and conditional controls.
- Improved contact line wrapping, keyboard focus and navigation spacing.
- Added reproducible development preview and automated audit/form tests.

## Verification

- 345 HTML pages: internal destinations, favicon presence and one main heading checked.
- Seven automated tests passed: legacy redirects, URL normalization, HTTP/404 behavior, local-page indexing, confirmed form success, failure recovery and French/honeypot handling.
- Browser review: desktop homepage; English and French contact pages at 375 px; mobile menu expansion.
- Existing photos, branding, public audience and contact information retained.

## Limits and next work

- Form success/error cases were simulated; inbox receipt and Formspree account configuration are not verified.
- Only the French overview and quote form are translated. Most detailed pages and policies are English.
- Browser review was representative, not a manual inspection of every page or device.
- Conversion events exist but no analytics destination is configured in the current source.
